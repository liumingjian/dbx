## 2. Orphans (obligations no ADR-0018 module owns)

- **运行状况 runtime condition (0021, 0032)**: items, worst-value fold, admission stop signal, change record, 待回收占用 aggregation, restart counters. Proposed: new `condition` module (pure fold + record) or `orchestration`. Tradeoff: orchestration already spans everything and would grow a second concern; a small pure module keeps the fold testable but adds a 12th package.
- **环境自检 environment check (0027, 0031, 0035)**: E0–E7 + memory tier + master-key item, startup and pre-admission, frozen conclusions. Proposed: new `environment` module (effectful probes via Kafka AdminClient/JMX/filesystem). Tradeoff: fits no existing module's side-effect shell (not SQL, not Connect REST); folding into `connector` would mix JMX/filesystem/Connector-J checksum into the Connect client.
- **诊断包 diagnostic package (0028)**: assembly, scrubber, manifest, bound, export audit. Proposed: `diagnosis` (TP §3.2 already says "Diagnosis engine … redacted packages"). Tradeoff: diagnosis is declared pure; package assembly reads workflow queries + fresh environment check, so it needs an effectful half (or orchestration use case calling a pure `diagnosis.package(inputs)`).
- **预估耗时 / 预计剩余 estimator (0019, 0024 split proposal, 0034)**: one backend estimator, replay, history refit, confidence. Proposed: `scheduling` (replay reuses `plan`/`admit`; pure). Tradeoff: keeps the replay next to the gates it must mirror; widens scheduling from "plan and admit" to "predict", and needs run-history rates from workflow as input.
- **废弃 abandonment (0023)**: task-level destructive flow, projected list. Proposed: `orchestration` use case + `contract` for projected list + `workflow` task lifecycle. Tradeoff: no new module, but orchestration's README/API grows; the list rendering must stay pure.
- **Discard 丢弃 / cleanup coordinator (0006, TP §3.2 "Cleanup coordinator")**: ownership-proven deletion of connectors/topics/subjects/secret projections/probe objects; cleanup request retries. Proposed: `orchestration` (driver) + `connector` (topic/subject/connector deletes). Tradeoff: cleanup retries are a long-running loop; orchestration becomes a scheduler of background jobs.
- **Release/upgrade (0035)**: package, script, tier, BOM, L4, rollback window. Proposed: new non-Java `release` sub-spec (script + Compose + `release.json`) plus small backend obligations in `web` (nonterminal-run query), `workflow` (rollback-window fact, key fingerprint), environment check. Tradeoff: a sub-spec, not a Java module; must not get an ArchUnit package.
- **Connect restart observation (0032, #79)**: plant `PUT /admin/loggers/dbx.incarnation` before first box and after each detected restart; `GET` each poll; 404 or `last_modified: null` ⇒ restarted; connection error/5xx ⇒ unreachable; one GET after DBX restart; fallback `describeClassicGroups` member UUID (needs clients ≥4.0). Proposed: `connector` (Connect REST client owns the calls; `judge` classifies restarted/unreachable/healthy). Tradeoff: natural fit; fallback needs Kafka AdminClient, which no module yet owns explicitly.
- **Connections and credentials (0006)**: 数据库连接, 凭据版本 encryption, 连接校验, TLS, archive, tombstone ledger, per-backup DEK erasure, secret projection file. No ADR-0018 row. Proposed: new `connection` module, or `gateway`. Tradeoff: gateway is "frozen connection binding + execute plans"; adding crypto, ledger, and CRUD makes it the widest module; a new module is cleaner.
- **Kafka AdminClient / topics (0002 disk, 0010 topics, 0027 E6 `describeLogDirs`, 0021 disk item, 0001 offsets, #79 fallback)**: no module named for Kafka. Proposed: `connector` (rename scope to "execution platform client"). Tradeoff: ADR-0018 says `connector` = Connect REST; extending it is a table amendment.
- **Routing snapshot, configuration fingerprint, execution signature producer (0008 "the core alone produces")**: Proposed: `contract` for routing snapshot (frozen with contract), `connector` for normalized config + fingerprint, `scheduling` for signature grouping. Tradeoff: three owners of one derived set risk drift; single owner (`connector`) keeps one derivation path.
- **Source baseline capture (0006, TP §4 step 8)** and **drift checks (0024)**: exact `COUNT(*)` + PK terminal values under freeze. Proposed: `preflight` (0018 row already lists "row-count" probe) or `validation` (drift is a comparison). Tradeoff: preflight is explicitly "not the baseline" in 0003/TP; validation already compares counts but only post-write.
- **Migration draft persistence + stage gating (0020)** and **task write freeze / task conclusion / split snapshot (0024)**: not in ADR-0004 aggregates. Proposed: `workflow`. Tradeoff: fits; requires ADR-0004 aggregate list extension.
- **Target leases / advisory locks / target generation OID (0006, 0023)**: Proposed: `workflow` (H2 lease, generation) + `gateway` (advisory lock inside plan execution). Tradeoff: split guard must be one orchestration step to stay atomic.
- **Secret projection to Connect ConfigProvider file (0006)**: Proposed: `connector`. Tradeoff: filesystem side effect in the Connect client module.
- **Backups (0004, 0006, 0023, 0035)**: hourly, pre-Flyway, pre-destructive, pre-discard, pre-abandonment; encrypted per-backup DEK. Proposed: `workflow` (owns H2). Tradeoff: needs crypto from the connections owner.
- **Installation-scoped status channel (0021 Consequences)** beside `RunProgressSource`: Proposed: `web` + `frontend`. Tradeoff: none; just absent from 0016.
- **"Continue admission" DBA command after second Connect restart / two-stuck pause (0032)**: Proposed: `orchestration` + `web`. Tradeoff: no run status or CONTEXT term exists for this paused state.
- **Manual deterministic sampling action (TP §9.3, 0020 drawer)**: Proposed: `validation` (plan) + orchestration (trigger). Tradeoff: none.
- **24 h box run limit (0001)**: Proposed: `connector.judge`. Tradeoff: none.

## 5. Cross-module interfaces (implied `api`)

Notation: `module.api.call(inputs) → output`; "consumed by" lists callers. Pure = no I/O.

- **dialect** (pure; consumes nothing)
  - `pair.map(SourceColumn, MappingOptions) → Supported|Unsupported` — contract, preflight, validation.
  - `pair.mapIdentifier(coord) → exact|rename<prefix>_<hash12>|alias|unsupported` — contract.
  - `source.metadataPlan(scope)`, `source.envelopeScanPlan(table, exprs)`, `source.preflightPlans(obligations)`, `source.baselinePlan(table)` (COUNT + PK terminal), `source.validationFactPlans(plan)`, `source.samplingPlan(key, n)` → typed SQL plans — preflight, orchestration, validation (executed via gateway).
  - `source.boundedReadRequirement(M) → typed settings (useCursorFetch, batch.max.rows, max.buffer.size, query.suffix, poll.interval.ms)` — connector.
  - `source.connectionSemantics() → Connector/J params` — gateway, connector.
  - `target.renderDdl(contract) → DDL` (via contract), `target.catalogReadPlan(coords)`, `target.compare(contract, catalogFacts) → differences`, `target.sinkSettings()`, `target.defaultWhitelist()`, `target.probePlan()`, `target.truncatePlan`, `target.dropPlan(oid)`, `target.dependencyPlan`, `target.grantSql(missing)`, `target.validationFactPlans(plan)` — contract, orchestration, validation.
  - `catalog.select(productVersion) → aggregate|unsupported` — gateway/connections, orchestration.
- **gateway** (effectful; consumes dialect plans)
  - `execute(plan, frozenBinding) → typed result | INCONCLUSIVE(reason)` with timeout + `Statement.cancel()` confirmation — orchestration (only caller per 0018), which feeds preflight/validation/contract.
  - `probeIdentity(connection) → product, version, instance identity, charset, tz, TLS` — connections, orchestration.
  - `withAdvisoryLock(targetKey, plans) → result` — orchestration (truncate, create, drop, discard).
- **preflight** (pure evaluation; plans via dialect)
  - `plan(scope, mappingDecisions) → PreflightPlan` — orchestration.
  - `evaluate(plan, facts) → PreflightResult{conclusion SUPPORTED|UNSUPPORTED|INCONCLUSIVE, findings[code, 预检发现影响], largeRecordFlag, M, plannedBytes}` — orchestration, contract, scheduling, estimator.
- **contract** (pure)
  - `assemble(metadata, mappingDecisions, mappingRules, preflightResult, routing, connectorPolicy) → TableWriteContract draft + fingerprint` — orchestration.
  - `renderDdl(contract) → DDL`, `renderSupplementalSql(metadataSnapshot, contract, scope) → statements` — orchestration, web (download, drawer).
  - `prove(contract, catalogFacts) → zero-difference | StructuredDifference[]` — orchestration.
  - `projectAbandonmentList(contracts, schemaCreated) → 预估废弃清单` — web.
  - `routingSnapshot(contracts) → RoutingSnapshot` (proposed) — connector, diagnosis, validation.
  - `codec.load(snapshotBytes, versions) → contract | NotInterpretable` — orchestration (recovery, 0035 old-release runs).
- **scheduling** (pure)
  - `plan(units[signature, bytes, M, largeRecord], limits) → SchedulingPlan{boxes, order, R per box}` — orchestration, estimator.
  - `admit(plan, occupancy{tasks, boxes, conns, disk, ΣR}, heap, B) → next box | wait(reason 平台内存预算|disk|connections…)` — orchestration, estimator replay.
  - `estimate(plan, rates{shape bands|history|observed}, ceiling) → range, 窗口下限, confidence` (proposed home) — orchestration, web.
  - `proposeSplit(remainingTables, freezeLimit) → table sets` (0024) — web/orchestration.
- **connector** (effectful Connect/Kafka/SR client + pure `judge`)
  - `buildConfig(contract, requirements, platformPolicy, boxClass) → normalized config + fingerprint + signature` — scheduling (signature), orchestration.
  - `createTopics(box)`, `startSink(box)`, `startSource(box)`, `stopSource(box)`, `stopSink(box)` idempotent — orchestration.
  - `observe(box) → facts{connector/task status, trace, topic end offsets, Sink lag, subject+schemaId}` — orchestration.
  - `judge(facts, baseline, history) → READ_COMPLETE|WRITE_COMPLETE|SUSPECTED_STUCK|STUCK|DUPLICATE|FAILED|RESTARTED|UNREACHABLE` (pure) — orchestration.
  - `plantIncarnation()`, `checkIncarnation() → present|restarted|unreachable` (#79) — orchestration.
  - `projectSecret(credentialVersion) → reference`, `removeSecret(ref)` — orchestration.
  - `deleteTopic`, `deleteSubject`, `listDbxResources() → owned|orphan` — orchestration (cleanup, discard, abandonment, 0035 leftovers), diagnosis package.
  - `diskUsage()` (describeLogDirs), `reachability()` — environment check, runtime condition.
- **validation** (pure evaluation)
  - `plan(approvedContract, pairCapabilities) → ValidationPlan` — orchestration (frozen into run).
  - `evaluate(plan, sourceFacts, targetFacts) → items[PASS|FAIL|INCONCLUSIVE|NOT_APPLICABLE|NOT_RUN, reason]` — orchestration.
  - `samplingPlan(plan, n=1000)`, `compareDrift(baseline, reread) → ok | INCONCLUSIVE/SOURCE_CHANGED` (proposed for 0024) — orchestration.
  - `conclude(items, disposition?) → unit outcome input` — orchestration/workflow.
- **diagnosis** (pure + package assembly)
  - `diagnose(occurrence, routingSnapshot, catalog) → Diagnosis{code, source kind, phase, root-cause domain, scope, message keys}` — orchestration.
  - `validateCatalog() → E0 result` — environment check.
  - `buildPackage(scope, inputs from workflow.query + env check + condition record + release.json) → zip + manifest` — web (via orchestration).
- **workflow** (effectful H2)
  - `command.*`: create/update draft; approve contract; create run (snapshot, baseline, plan, validation plan, env-check conclusions); unit/box transitions; record progress (coalescible); record occurrence/diagnosis; record timeline/stage attempt; acquire/release target lease; new target generation (with OID); cleanup request CRUD; task lifecycle (abandon*); task write freeze + reconfirm; condition change; rollback-window close; backup — orchestration only.
  - `query.*`: task list (tasks + drafts), task detail, run projection/status, units, timelines, validation report, preflight findings, run snapshot, task conclusion, estimates, condition record, "any nonterminal run?" — web, orchestration, diagnosis package.
- **orchestration** (use cases)
  - Offers to web: `startRun(draftId)`, `cancelRun(runId, finishing?)`, `discardRun`, `abandonTask(confirmedList)`, `retryAbandon`, `remigrate(runId) → draftId`, `copyAsDraft(taskId)`, `recordDisposition(unitId, reason)`, `runManualSampling(unitId)`, `continueAdmission(runId)`, `checkConnection(connId)`, `runPreflight(draftId)`, `reconfirmTaskFreeze`, `exportPackage(scope)`, `runEnvironmentCheck()`.
  - Consumes: dialect, gateway, preflight, contract, scheduling, connector, validation, diagnosis, workflow.command/query, environment check, runtime condition, connections.
- **web** (HTTP adapters): endpoints for every orchestration use case and workflow query; `RunProgressSource` snapshot endpoint (run-scoped); installation-scoped status endpoint (0021); supplemental-SQL download; diagnostic package download; nonterminal-run check for `dbx upgrade` (0035); 关于/release version.
- **frontend**: consumes web via the hand-written TS contract (glossary field names) and two progress seams (`RunProgressSource`, installation status).
- **proposed `environment`**: `check(scope: startup|preAdmission(run)) → items[E0…E8, conclusion, observed, expected, snapshot version]` — orchestration, runtime condition, diagnosis package; consumes connector (E2/E3/E4/E6), diagnosis (E0), JMX, filesystem, `release.json`.
- **proposed `condition`**: `fold(items) → value`, `record(change)`, `admissionAllowed() → bool + reason` — scheduling/orchestration (admission), web, diagnosis package.
- **proposed `connection`**: connection CRUD/archive, credential version encrypt/decrypt/destroy, tombstone ledger, master-key fingerprint — orchestration, gateway, connector (secret projection), workflow (backup DEK).
- **release** (non-Java): consumes web (nonterminal-run check), H2 backup/restore procedure, `release.json`; provides tier + heaps to Compose, master key file, `drivers/` mount.
